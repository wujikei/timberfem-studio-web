# TimberFEM Studio · 公开项目入口

网址：<https://wujikei.github.io/timberfem-studio-web/>

本仓库只托管公开项目入口、页面样式和两项经过清洗的静力数值摘要。完整工作台源码保留在私有仓库 [wujikei/TimberFEM-Studio](https://github.com/wujikei/TimberFEM-Studio)。

## 使用方式

1. 打开上述 HTTPS 网址，查看说明和数值依据。
2. 下载 [0.13 导师交付包](https://github.com/wujikei/TimberFEM-Studio/releases/tag/v0.13.0)，或取得项目负责人直接提供的 ZIP。私有下载需要授权；未授权时显示 404。
3. 完整解压导师包，先打开 `00_请先看我.html`，再双击 `【双击开始】TimberFEM Studio.cmd`。单独源码包使用根目录的 `【双击启动】TimberFEM Studio.cmd`。首次配置需联网，后续通过浏览器建模和分析，无需修改 Python。
4. 页面中的“临时在线试用”连接独立、受密码保护的实际计算服务。账号与密码单独提供；临时域名依赖演示电脑开机、联网、服务与隧道运行。页面中的本机链接也需要先启动本机服务。

GitHub Pages 提供静态介绍页，不执行 Python 或 OpenSees。公开页面不包含工作台源码、研究项目数据、原始试验、未发表论文或访问凭据。

## 当前版本 0.13.0

原始 UTF-8 CSV 可以在工作台中选择位移/力通道、单位、方向、原单位零点及连续样本区间；先预览再加入标定。原件、SHA-256、处理映射和试件来源随标定和动力快照保留，并能从离线报告下载。软件识别同一采集通道的重复使用，避免把简单拆段提升为独立试件证据。

已有研究路径包括正交弹性面板、梁—板—钉弹性精细墙、有限周边传力弹性墙、弹性曲线标定及留出比较、单自由度与2–20层剪切型线性动力、理想弹性柱P-Δ/特征屈曲、单轴循环连接以及完整离线报告。

当前练习 CSV 是自行生成的人工数组，不是真实木墙试验。哈希只能检查内容一致性，不能认证试验真实性。真实木墙试验验证、通用三维动力、整墙非线性及规范安全验算仍待完成；计算成功不等于结构安全。
